# Путь B: локальная демонстрация

Публичный хостинг не используем. Проверяющий смотрит локальный запуск и короткое видео.

## Что снять на видео (1–2 минуты)

1. Терминал: `docker compose up` (или уже запущенный контейнер) и строка `Uvicorn running`.
2. Браузер: http://127.0.0.1:8000
3. Форма: ФИО, телефон, номер заказа (можно демо: Анна Котова, +7 900 111-22-33, 45812) и текст обращения.
4. Кнопка «Разобрать обращение» → на экране тип и черновик ответа.
5. DBeaver: файл `D:\MANAGER\data\tickets.db`, таблицы `clients` и `tickets` — новая строка с тем же текстом и черновиком.

## Скриншоты (положить сюда)

- `demo/screen-form.png` — форма с ответом
- `demo/screen-dbeaver.png` — строка в `tickets`
- `demo/screen-docker.png` — терминал Docker (по желанию)
